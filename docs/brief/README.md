# Lecture du brief par chantier

La source fonctionnelle canonique du projet reste la
[note de cadrage DSI](../cadrage_dsi.md). Les trois documents ci-dessous n’ajoutent aucune exigence :
ils relient chaque chantier à son code, ses tests et ses preuves.

| Chantier | Objectif | Lecture directe |
|---|---|---|
| 1 — RAG avancé | Ingestion, recherche hybride, citations, refus et mesure E6 | [01-rag-avance.md](01-rag-avance.md) |
| 2 — Text-to-SQL | Schéma sémantique, génération contrôlée, SQL read-only et tools figés | [02-text-to-sql.md](02-text-to-sql.md) |
| 3 — MCP et matrice | Huit tools, autorisation par profil, erreurs typées et audit | [03-mcp-matrice-acces.md](03-mcp-matrice-acces.md) |

Le [livrable formateur](../livrable/README.md) rassemble ensuite les cinq éléments de conception,
la présentation, les preuves et le guide d’accès au serveur.
